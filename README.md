# HyperTV

面向 Android TV / Google TV 的 M3U 直播源播放器。**电视端开机即看，所有配置交给 WebUI。**

电视观众要的是一台"正经 IPTV"：开机自动播放、遥控器换台、一键收藏、节目表。而导入源、整理频道、配置 EPG 这些脏活累活，全部放在手机/电脑浏览器里完成——电视端零配置、零文本输入、零文件选择。

> 当前处于设计定型阶段：spec 与开发 tickets 已发布，核心代码尚未开始实现。

## 特性

- **开机即看**：自动加载上次观看的频道并直接播放，冷启动到播放目标 <3s
- **机顶盒式遥控体验**：上下键换台（目标 <500ms）、OK 呼出频道列表、星号键一键收藏、Info 看节目、数字键直达频道号
- **WebUI 唯一配置入口**：导入 M3U URL / 上传文件、频道与分组管理、收藏管理、EPG 配置，全部在浏览器完成，改动实时同步到电视端
- **多直播源管理**：增量合并导入（重复导入保留收藏与自定义顺序）、源级刷新与删除
- **EPG 节目表**：XMLTV 解析 + 三级频道匹配，电视端节目信息浮层与全屏节目表
- **本地优先**：数据全部存于设备 SQLite，无账号、无云服务、无外部依赖
- **零系统依赖**：不调用系统输入法、不调用系统文件选择器、无 WebView

## 快速开始

```bash
# 构建 Debug APK（需 Android SDK，API 28+）
./gradlew assembleDebug
```

安装到电视/盒子后，首次启动的引导页会显示 WebUI 地址与二维码——用手机浏览器打开即可开始导入直播源。

## 架构概览

```
┌─────────────────────────────────────────────┐
│              Android App（单进程）             │
│                                             │
│  ┌──────────────┐      ┌────────────────┐  │
│  │ 电视端播放器   │      │  WebUI 静态页    │  │
│  │ Compose for TV│      │  Vue3 打包进 APK│  │
│  └──────┬───────┘      └───────┬────────┘  │
│         │   同进程 Flow          │ HTTP/TCP  │
│  ┌──────┴───────────────────────┴────────┐  │
│  │        Repository（统一数据逻辑）        │  │
│  └──────┬───────────────────────────────┘  │
│  ┌──────┴────────┐   ┌──────────────────┐  │
│  │  Room (SQLite) │   │  Ktor :8080      │  │
│  └───────────────┘   └──────────────────┘  │
│  媒体引擎：Media3 (ExoPlayer)               │
└─────────────────────────────────────────────┘
```

- 电视端与 WebUI 共享同一数据层（Room Flow 订阅，天然实时同步）
- 媒体播放：单 ExoPlayer 实例复用，切换 MediaItem 实现换台
- 局域网服务：Ktor 监听 `0.0.0.0:8080`，前台服务保活

## 技术栈

| 端 | 技术 |
|---|---|
| 电视端 | Kotlin · Jetpack Compose for TV · Media3 (ExoPlayer) · Coil |
| 数据层 | Room (SQLite) · Kotlinx Serialization · Hilt |
| 服务层 | Ktor (CIO) · ZXing（二维码） |
| WebUI | Vue 3 · Vite · TypeScript（构建产物打进 APK） |
