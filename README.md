# HyperTV

面向 Android TV / Google TV 的 M3U 直播源播放器。**电视端开机即看，所有配置交给 WebUI。**

电视观众要的是一台"正经 IPTV"：开机自动播放、遥控器换台、一键收藏、节目表。而导入源、整理频道、配置 EPG 这些脏活累活，全部放在手机/电脑浏览器里完成——电视端零配置、零文本输入、零文件选择。

> ✅ **v1 MVP 已实现**：M3U/txt 源导入播放、多源增量合并、五级 EPG 匹配、WebUI 全量配置、频道浮层 + 节目时间轴。当前为 public 仓库。

## 特性

- **开机即看**：自动恢复上次观看的频道并直接播放
- **机顶盒式遥控体验**：上下键换台、OK 呼出频道浮层、数字键直达频道号、星号键 / 遥控器 BOOKMARK 键一键收藏
- **频道浮层**：左右两栏——分组 + 频道列表（收藏 / 全部 / 各分组）、当前节目简介 + EPG 时间轴（当前整点 -1h ~ +3h 窗口，北京时间显示）
- **WebUI 唯一配置入口**：M3U 链接 / 文件上传导入、txt 直播源（`名称,URL` + `#genre#` 分组）、频道与分组管理、收藏管理、EPG 源与匹配规则，全部在浏览器完成，改动实时同步到电视端
- **多直播源管理**：增量合并导入（重复导入保留收藏与自定义顺序）、源级刷新与删除、消失频道自动隐藏
- **EPG 节目表**：XMLTV 解析（含 gzip 源）、多 EPG 源合并去重、**五级频道匹配**（tvg-id 精确 → 忽略大小写 → 名称归一化 → 前缀 → 包含）+ 关键字规则 + 手动绑定，匹配来源可追踪；频道号动态生成不空洞
- **动态服务端口**：默认不固定 8080，随机高位端口持久化，冲突自动重试
- **本地优先**：数据全部存于设备 SQLite，无账号、无云服务、无外部依赖
- **零系统依赖**：不调用系统输入法、不调用系统文件选择器、无 WebView

## 快速开始

依赖：Android SDK（API 28+）、JDK 17、Node.js + pnpm（构建 WebUI）。

```bash
# 构建 Debug APK（首次构建自动 pnpm install + 打包 WebUI 进 assets）
./gradlew assembleDebug

# 构建 Release APK（产物在 app/release/）
./gradlew assembleRelease
```

> 若 pnpm 不在系统 PATH（如 WinGet 安装），在 `local.properties` 添加 `pnpm=<绝对路径>`（本机配置，不入库）。

安装到电视/盒子后，首次启动的引导页会显示 WebUI 地址与二维码——用手机浏览器打开即可开始导入直播源。

## 架构概览

```
┌─────────────────────────────────────────────┐
│              Android App（单进程）             │
│                                             │
│  ┌──────────────┐      ┌────────────────┐  │
│  │ 电视端播放器   │      │  WebUI 静态页    │  │
│  │ Compose for TV│      │ Vue3 打包进 APK│  │
│  └──────┬───────┘      └───────┬────────┘  │
│         │   同进程 Flow          │ HTTP/TCP  │
│  ┌──────┴───────────────────────┴────────┐  │
│  │        Repository（统一数据逻辑）        │  │
│  └──────┬───────────────────────────────┘  │
│  ┌──────┴────────┐   ┌──────────────────┐  │
│  │  Room (SQLite) │   │  Ktor（动态端口）  │  │
│  └───────────────┘   └──────────────────┘  │
│  媒体引擎：Media3 (ExoPlayer, HLS)           │
└─────────────────────────────────────────────┘
```

- 电视端与 WebUI 共享同一数据层（Room Flow 订阅，天然实时同步）
- 媒体播放：单 ExoPlayer 实例复用，切换 MediaItem 实现换台；播放失败重试 3 次后自动切下一频道
- 局域网服务：Ktor 监听动态端口（49152–65535，持久化复用），前台服务保活

## 技术栈

| 端 | 技术 |
|---|---|
| 电视端 | Kotlin · Jetpack Compose for TV · Media3 (ExoPlayer) · Coil |
| 数据层 | Room (SQLite) · Kotlinx Serialization · Hilt |
| 服务层 | Ktor (CIO) · ZXing（二维码） |
| WebUI | Vue 3 · Vite · TypeScript · Element Plus（pnpm 构建，产物打进 APK） |
