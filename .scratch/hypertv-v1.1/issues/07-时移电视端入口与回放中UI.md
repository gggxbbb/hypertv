# 07 — 时移电视端入口与回放中 UI

**What to build:** 电视端回放入口与回放态体验：在频道浮层右栏与全屏 Guide 时间轴上长按已播出节目（含正在播的从头回放）触发回放；回放中显示"回放中"标识与进度竖线；仅对 catchupSupported 频道开放入口，无 EPG 频道无入口。

**Blocked by:** 05 — 时移播放核心、06 — 回放能力探测

**Status:** ready-for-agent

- [ ] 浮层右栏/Guide 时间轴：长按"已播出"节目条触发回放（playseek 起点=节目开始时间）；正在播的节目允许从头回放
- [ ] 仅 `catchupSupported=true` 的频道开放回放入口（长按无反应或明确不出现回放动作）；无 EPG 匹配的频道无入口
- [ ] 回放中浮层显示"回放中"标识；时间轴游标指向回放进度位置（而非当前时间）
- [ ] 与既有按键行为不冲突（长按与 OK/左右键的冲突处理）——冒烟测试重点覆盖
- [ ] 模拟器冒烟验证：长按回放、回放中 seek、播完自动回直播、回放失败回直播、不支持频道无入口
