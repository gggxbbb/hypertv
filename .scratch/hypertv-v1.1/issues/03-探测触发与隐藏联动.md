# 03 — 探测触发与隐藏联动

**What to build:** 把探测引擎接入业务闭环：导入/刷新后自动触发探测（知道该测谁、该跳过谁），探测结果驱动频道的自动隐藏/恢复——让"失效频道自动从电视端消失、复活自动回来"真正工作起来。

**Blocked by:** 02 — 探测执行器（ProbeRunner）

**Status:** ready-for-agent

- [ ] 导入/刷新直播源后自动触发：新增频道必测、`checkResult=invalid` 的重测、其余 24h 内测过的跳过（缓存策略）
- [ ] 新导入数据可中止进行中的旧探测任务
- [ ] 无效频道自动隐藏：`hiddenSource=probe`（电视端消失、WebUI 可见可恢复）
- [ ] 探测到有效自动恢复：`hiddenSource=probe` 的频道在探测结果为 valid 时恢复显示
- [ ] `hiddenSource=manual` 的频道跳过探测（尊重用户手动隐藏意图）
- [ ] 触发范围选择逻辑单测：新增/无效/缓存跳过、manual 跳过、自动恢复语义
