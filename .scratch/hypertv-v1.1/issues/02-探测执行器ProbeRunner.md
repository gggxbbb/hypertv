# 02 — 探测执行器（ProbeRunner）

**What to build:** 频道的有效性探测引擎：对频道 URL 发起 HTTP 检查并给出三态结论（未知/有效/无效），控制并发与超时避免打爆源站，并把结果写回数据库——让"导入后自动探测"和"WebUI 手动重测"都建立在同一个可复用引擎上。

**Blocked by:** 01 — 数据层 schema v6 + 字段扩展

**Status:** ready-for-agent

- [ ] 探测方法：GET 频道 m3u8 列表，校验含 `#EXTM3U` 与有效 `#EXTINF` 条目；连接超时 5s、总超时 10s、失败重试 1 次
- [ ] 并发控制：并发 8、每频道间隔 ≥100ms、HTTP 连接复用（规避 CDN 短时高频拒答）
- [ ] 三态结果（unknown/valid/invalid）+ 探测耗时 + 失败原因写回 channels 表
- [ ] 播放失败信号联动：重试 3 次耗尽计一次无效信号，累计 3 次标记 invalid，成功播放一次重置
- [ ] 探测任务可中止（后续新导入/新触发时取消旧任务）
- [ ] ProbeRunner 单测（注入 fake HTTP）：三态判定、超时/重试、并发调度、失败信号累计与重置、中止语义
