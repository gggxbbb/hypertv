# 05 — 时移播放核心

**What to build:** 让播放器具备回放历史流的能力：解析 catchup 模板生成 playseek URL（append/default 两种模式），播放器区分"直播/回放"两种模式并在回放结束或失败时自动回到直播——这是电视端时移体验的播放引擎。

**Blocked by:** 01 — 数据层 schema v6 + 字段扩展

**Status:** ready-for-agent

- [ ] 播放层 Channel 模型补 catchup/catchupDays/catchupSource 三字段（解析/存储/管理 API v1 已通）
- [ ] CatchupUrlBuilder：按 catchup-source 模板替换 `${(b)}`/`${(e)}`（紧凑 `yyyyMMddHHmmss`）生成 playseek URL；支持 `append`/`default` 两种模式；`shift` 模式标记不可用；异常/缺失模板降级为不支持
- [ ] PlayerController 增加 `PlaybackMode`（live/catchup），播放回放流时切换模式
- [ ] 回放流 `STATE_ENDED` → 自动重载原直播 URL 切回 live 模式
- [ ] 回放加载失败 → 提示 + 自动回直播
- [ ] CatchupUrlBuilder 纯函数测试（两种模式/变量替换/降级）+ PlayerController 状态机测试（fake player 驱动 live→catchup→ended→live）
