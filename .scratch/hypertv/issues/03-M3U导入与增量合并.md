# 03 — M3U 导入与增量合并

**What to build:** 从 URL 拉取或文件上传解析 M3U/M3U8（含 GBK/UTF-8 编码识别），输出规范化频道列表（名称/URL/分组/台标/tvg-id/catchup 字段）并在导入前生成解析预览。导入执行按频道 URL 增量合并：已存在频道保留收藏与自定义顺序、更新元数据，新增频道追加，源内消失频道标记隐藏。API：POST /api/playlist/import、POST /api/playlist/upload。

**Blocked by:** 02 — 数据层：Room schema 与 Repository

**Status:** ready-for-agent

- [ ] URL 导入 5000 频道解析 <5s
- [ ] UTF-8 与 GBK 编码的 M3U 均可正确解析
- [ ] 导入前返回预览（频道数、分组列表）
- [ ] 重复导入同一源：收藏与自定义顺序保留，消失频道标记隐藏而非删除
- [ ] 解析器单测覆盖异常行、缺失字段、空源
