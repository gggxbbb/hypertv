# 01 — 项目骨架与基础设施

**What to build:** App 启动后 Ktor 服务在 8080 端口监听，手机浏览器访问 `/api/status` 能看到版本、局域网 IP 与端口；首次启动（无直播源）时电视端显示引导画面，展示 WebUI 地址与二维码。包含：构建依赖装配（Media3/Ktor/Room/Hilt/Coil/ZXing/序列化）、明文 http 放行的网络安全配置、前台服务保活（含常驻通知、进程被杀后自动恢复）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 冷启动后 Ktor 服务就绪，`GET /api/status` 返回 {version, ip, port}
- [ ] 手机浏览器可访问 WebUI 根路径（静态占位页）
- [ ] 无直播源时电视端引导页显示 IP + 二维码，二维码可被手机扫码打开 WebUI
- [ ] 网络安全配置允许明文 http 流量
- [ ] 服务以前台服务方式运行，App 被杀后自动恢复（START_STICKY）
