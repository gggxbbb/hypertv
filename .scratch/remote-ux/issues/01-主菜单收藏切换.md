# 01 — 主菜单收藏切换

**What to build:** 用户家电视遥控器只有 dpad + 菜单键（无星号/红键/Bookmark），收藏切换现在只绑在这些键上（`PlayerKeyHandler.handleFavoriteToggle`），遥控器无法触发。在主菜单加一个动态项「★ 收藏本频道 / ☆ 取消收藏本频道」，用 OK 键即可切换当前播放频道的收藏状态。

**Blocked by:** —

**Status:** resolved

## 设计要点

- 菜单项顺序改为：节目表 / 收藏本频道（动态，第 2 项）/ 收藏列表 / 回放（v2 占位，disabled）/ 关于。
- 菜单项文案随当前播放频道收藏状态动态显示：
  - 未收藏 → 「★ 收藏本频道」
  - 已收藏 → 「☆ 取消收藏本频道」
- OK 确认该菜单项：`favoriteStore.toggle(currentChannelId)` → 右上角提示（复用现有 favoriteHint：「已收藏」/「已取消收藏」）→ **关闭主菜单回播放页**（用户已确认此交互）。
- 焦点仍只在启用项间移动（禁用占位「回放」不可聚焦）；收藏项始终启用（即使当前频道为空列表也不会有播放页）。
- 注意：`PlayerScreen` 的 `onMenuConfirm` 现在硬编码 index（0 节目表 / 1 收藏列表 / 2 关于），插入收藏项后索引全部后移，**必须改用显式常量映射，禁止魔法数字**。
- `MainMenuPanel` 的 `MAIN_MENU_ITEMS` 是静态常量、`MAIN_MENU_ENABLED_COUNT` 静态计数，需改为接收当前频道收藏状态的动态列表；`MainMenuState.moveFocus` 已支持外部传入 focusableCount，确认无需改动或仅小改。

### 实现要点

- `MainMenuPanel.kt`：删除静态 `MAIN_MENU_ITEMS` / `MAIN_MENU_ENABLED_COUNT`，改为动态函数
  `mainMenuItems(isFavorite)`（5 项，收藏项第 2 位，文案随收藏状态切换「★ 收藏本频道 / ☆ 取消收藏本频道」）
  与 `mainMenuEnabledCount(items)`；`MainMenuPanel` 改为接收 `items: List<MenuItem>` 渲染。
- `PlayerScreen.kt`：`menuItems` 由当前频道收藏状态派生（以 `favoriteStore.favorites` Flow 为单一真源，
  不依赖 channels 快照的 isFavorite）；`PlayerKeyHandler` 新增 `menuItems`/`menuEnabledCount` 字段，
  `handleMenuKey` 改用动态计数；`onMenuConfirm` 改用显式常量映射
  （`MENU_INDEX_GUIDE/TOGGLE_FAVORITE/FAVORITES/ABOUT`，禁止魔法数字），OK 收藏项分支：
  `favoriteStore.toggle(currentChannelId)` → 复用 `onToggleFavorite` 提示 → 关闭菜单回播放页。
- `MainMenuState.kt`：仅修正过期注释（首个启用项为「节目表」），`moveFocus` 逻辑无需改动。
