# 内嵌服务采用动态端口（随机 + 持久化复用 + 失败重试）

原设计固定监听 8080（spec 9.3），但 8080 是常用端口，电视盒子上其他 App/服务占用时会导致内嵌 Web 服务无法启动。改为：启动时优先复用 app_config 中保存的上次 listen 成功端口；无保存或绑定失败时在 IANA 动态端口段 49152-65535 随机生成新端口重试（最多 10 次）；绑定成功即持久化。连接信息（IP + 实际端口）通过引导页/关于页展示，用户每次从"关于"页获取。代价：端口不固定，但 WebUI 入口通过二维码/关于页传递，用户无感知；安全上随机端口反而降低被扫描的概率。
