# 频道浮层改为左分组/右 EPG 布局

原频道浮层为"底部面板 + 顶部横向分组标签（全部→分组→收藏）+ 频道列表"。用户需求改为**左右两栏**：左栏 = 分组标签（**收藏作为第一个**）+ 频道列表（行内收藏★标记）；右栏 = 选中频道的 **EPG 时间轴**（窗口节目条 + 当前时间线 + 现在播出行）。同时 **BOOKMARK 键（书签）加入收藏/取消**（与星号键、红键并列）。理由：频道选择与节目表并排，一屏完成"找台 + 看节目"；收藏置顶符合高频操作。

## 修订记录（2026-08-17）

- **布局定稿**：浮层改为**全高**（原屏底 72% 面板），左栏占 40% 宽、分组标签 + 频道列表延伸到屏幕底；右栏收为 **100dp 矮条**（频道名 + 现在播出 + 时间轴，够显示即可），下方露出视频；左右栏之间**无分隔线**。
- **时间轴窗口**：**4h**，起点 = 当前整点 **-1h**（即 [当前整点-1h, +3h)，如 14:37 → [13:00, 17:00)），浮层右栏与全屏 Guide 页共用同一窗口函数（`guideWindowStartFor`）；期间尝试过的 6h±3h、4h±2h + 半点裁切等方案均被用户否决。
- **显示时区**：固定 **GMT+8**（`EPG_ZONE = Asia/Shanghai`），XMLTV 源（如 epg.51zmt.top）时间标记 +0800，解析后按此时区显示，不随系统时区（模拟器/真机可能为 GMT 导致差 8 小时）。
- **视觉细节**：节目条文字为白色（灰底）；当前时间游标以覆盖层绘制在节目条**上方**；频道名与节目标题超长时 **marquee 横向滚动**（`basicMarquee`，velocity 30dp）。
