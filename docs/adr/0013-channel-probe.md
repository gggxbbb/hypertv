# 频道有效性探测：全自动闭环，电视端零感知

导入型 IPTV 源（如 282 频道的 JSIPTV）失效频道是常态，手动逐个排查不可行；v1 已有可恢复的隐藏机制（isHidden），探测以"自动隐藏失效频道"落地。决策：探测由**导入/刷新后自动触发 + WebUI 手动重测**（新增频道必测、无效频道重测、其余 24h 缓存），结果三态（未知/有效/无效）落 channels 表（v5→v6）；无效自动隐藏且 `hiddenSource=probe`，探测到有效自动恢复；用户手动隐藏（`hiddenSource=manual`）跳过探测。探测方法为 GET m3u8 列表并校验 #EXTM3U/EXTINF（连接 5s / 总 10s 超时，失败重试 1 次，并发 8、每频道间隔 ≥100ms 防 CDN 短时高频拒答），播放失败重试 3 次耗尽计无效信号、累计 3 次自动隐藏、成功播放重置。电视端完全无感知（无任何探测 UI），全部展示与操作在 WebUI 频道列表（有效性列/过滤/重测/进度/源健康统计）。

**Considered Options**: 只标记不自动隐藏（对大量级源无实际价值，弃）；自动隐藏不区分来源（无法尊重用户手动隐藏意图，弃）。
