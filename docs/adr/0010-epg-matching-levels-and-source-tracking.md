# 频道-EPG 匹配扩展：四级前缀、五级包含与来源追踪

原三级匹配（tvg-id 精确→忽略大小写→名称归一化精确）漏掉"本地名=简称+后缀"场景（`CCTV-2 财经` vs EPG `CCTV2`）。扩展为五级：新增**四级归一化前缀**（边界检查防 `CCTV-1` 误配 `CCTV-10`，清晰度后缀白名单 4k/8k/hd/超清等放行）与**五级归一化包含**（长度阈值 4、最长匹配优先、ASCII 边界防 `cctv1` 子串误配 `cctv10`）。同时持久化匹配来源 `epgMatchSource`（manual/rule/level1-5/null）与手动绑定标记 `epgManual`——前者供 WebUI 详情卡片展示"怎么匹配上的"，后者保证手动绑定不被重导入/刷新覆盖。已知取舍：前缀优先于包含（`CCTV-风云剧场` 若 EPG 同时有 `CCTV` 台则绑 CCTV，想绑风云剧场用规则）。
